# Rove Creative

Website company profile **Rove Creative** — rumah bagi ide-ide kreatif.
**Capture. Create. Empower.**

🌐 Live: https://rovecreative.github.io/AboutUs/

## Struktur

| File | Isi |
|---|---|
| `index.html` | Seluruh kode website (HTML, CSS, JavaScript) |
| `assets/` | Logo dan foto |
| `.nojekyll` | Agar GitHub Pages menyajikan file apa adanya |

## Bagian website

1. Hero — *Create Your Story Now.*
2. Tentang Kami — Rumah bagi ide-ide kreatif
3. Filosofi — Capture, Create, Empower
4. Layanan — Content Creation, Cinematography, Editing, Education, Digital Product
5. Galeri di balik layar
6. Kontak — formulir brief proyek

## Mengubah konten

- Teks layanan ada di `index.html`, di dalam array `const S=[...]` pada bagian `<script>`.
- Foto galeri ada di array `const W=[...]`.
- Ganti gambar dengan mengunggah file baru bernama sama ke folder `assets/`.
